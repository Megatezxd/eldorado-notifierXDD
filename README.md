# مراقب الدورادو (Eldorado Notifier)

تطبيق أندرويد غير رسمي بيفحص إشعارات حسابك على الدورادو عن طريق الـ Seller API،
ويبعتلك إشعار على الموبايل (مع صوت واهتزاز) لما يحصل أي حاجة جديدة:
أوردر جديد، تسليم، نزاع، مشتري كلمك، محادثة جديدة، تقييم، تذكير بتفاصيل التسليم... إلخ.

## إزاي تطلع ملف الـ APK (من غير Android Studio)

1. اعمل حساب على GitHub لو معندكش، وأنشئ Repository جديد (Private أحسن).
2. ارفع كل ملفات المشروع ده فيه (Add file > Upload files، واتأكد إن فولدر `.github` اتحمّل).
3. افتح تاب **Actions**، هتلاقي workflow اسمه **Build APK** بيشتغل لوحده (أو دوس Run workflow).
4. بعد حوالي 3-5 دقايق افتح الـ run الأخضر ونزّل **eldorado-notifier-apk** من تحت.
5. فك الضغط، وانقل `app-debug.apk` للموبايل وثبته (اسمح بالتثبيت من مصادر غير معروفة).

بديل: افتح المشروع في Android Studio واختار Build > Build APK.

## الإعداد على الموبايل

1. من الدورادو: **Dashboard > Seller API** > Generate credentials (اختار مدة، مثلاً 365 يوم).
2. افتح التطبيق وادخل الـ Client ID والـ Client Secret.
3. دوس **تجربة الاتصال** للتأكد.
4. دوس **حفظ وتشغيل المراقبة** واسمح بالإشعارات.
5. دوس **استثناء التطبيق من توفير البطارية** واختار "غير مقيّد/Unrestricted".
   في شاومي/ريدمي كمان فعّل "Autostart" وقفل التطبيق في Recent Apps (قفل 🔒).
   في سامسونج: Battery > Background usage limits > Never sleeping apps.

## ملاحظات

- الـ Secret بيتخزن مشفر على الموبايل (Android Keystore) ومبيتبعتش لأي مكان غير الدورادو.
- التطبيق **مبيعلمش الإشعارات "مقروءة"** على الدورادو، فهتفضل ظاهرة عندك على الموقع.
- أول مرة بتشغله بيعمل تنبيه واحد بعدد الغير مقروء، وبعدها بينبهك بس بالجديد.
- لو الـ credentials انتهت أو اتغيرت، هيجيلك تنبيه "المراقبة واقفة"؛ ولّد واحدة جديدة وحطها.
- الـ API مش بتوفر قراءة نص الرسايل نفسها. اللي بيوصل هو إشعارات المحادثات
  (مشتري كلمك / محادثة جديدة / رسالة لسه متقراتش).
